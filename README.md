# Boubekki Mohamed Akram — Filmmaker & Videographer Portfolio

A clean, responsive portfolio website for filmmaker and videographer **Boubekki Mohamed Akram**.

## Structure

```
├── index.html              # Main portfolio page
├── privacy.html            # Privacy policy page
├── css/
│   └── styles.css          # Design system & responsive styles
├── js/
│   └── app.js              # Interactive timeline controls & player logic
└── assets/
    ├── images/
    │   └── akram.webp      # Portrait photo
    └── logos/              # Company brand marks & work milestone avatars
```

## Features

- **About & Bio**: Overview statement, typography, and portrait.
- **My Services**: Cards with service offerings and minimal preview placeholders.
- **Work Experience Timeline**:
  - **Desktop (PC)**: Horizontal scrolling timeline with custom rail line, concentric milestone nodes, and dates.
  - **Mobile**: Vertical chronological timeline.
- **Direct Contact & Socials**: Email and social links.
- **Responsive**: Mobile-first architecture, optimized for phones (320px+), tablets, laptops, and desktop screens.
